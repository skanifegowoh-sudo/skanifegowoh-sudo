## Source availability notes

- Public repositories provide source files and documentation that visitors can inspect immediately.
- Private repositories contain project files but are **not visible to most employers or other visitors**. Read-only access or code walkthroughs can be arranged where rights and confidentiality permit.
- Several source trees are selected snapshots rather than continuously synchronised mirrors of deployed products.
- Windows-specific Sanctus Compute Lab source, unreviewed experimental work, private AI service tokens, customer data and large model/corpus files are **not** included in the public code.
- Screenshots, demo behaviour and repository commits should be used together when evaluating ownership and hands-on experience.
